# Getting help

Thanks for using Stellar Stream Hive. Pick the route that matches what you need.

| You want to... | Go to |
| --- | --- |
| Ask a question or get help using the app | [Open a question issue](https://github.com/Stellar-Hive/stellar-stream-hive-frontend/issues/new?template=question.md) |
| Report something broken | [Open a bug report](https://github.com/Stellar-Hive/stellar-stream-hive-frontend/issues/new?template=bug_report.md) |
| Suggest a feature | [Open a feature request](https://github.com/Stellar-Hive/stellar-stream-hive-frontend/issues/new?template=feature_request.md) |
| Set up the project or understand the code | [README](./README.md) and [CONTRIBUTING](./CONTRIBUTING.md) |
| Read the design decisions | [Architecture decision records](./docs/adr/README.md) |
| Contribute a change | [CONTRIBUTING](./CONTRIBUTING.md) |

Questions are not bugs. Please use the question template so they do not get filed as bug
reports.

Please do not report security vulnerabilities in a public issue. Share them privately with
the maintainers instead, and do not include exploit details in any public thread.
